# Curso de Muestreo

Curso interactivo desarrollado para la Unidad II de la materia de Estadística.

## Contenido

- Introducción al muestreo y métodos probabilísticos
- Muestreo no probabilístico y comparación de métodos
- Distribuciones muestrales (media, proporción, varianza)
- Aplicación integral con problema de Ingeniería de Software

## Instalación

```r
library(swirl)
install_course_directory("ruta/al/Curso_Muestreo")
swirl()
```
